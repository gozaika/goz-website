# Localization release gate

Hindi (`hi-IN`) and Telugu (`te-IN`) columns intentionally remain blank. These are production marketing claims, so machine translation alone is not release approval.

For each locale, a fluent human reviewer must verify meaning, naturalness, script rendering, line length, punctuation, the pickup-only operating model, and the absence of pricing, demand, revenue, or performance promises. The reviewer records their name, date, and `approved` status in a reviewed copy of the CSV. Only approved strings may enter localized layouts.

The `goZaika` name, `BAM Bag`, URL, email address, canonical logo, and BAM flavor-drop mark remain unchanged unless the brand owner explicitly approves a localized naming rule.
